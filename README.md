## Intro

`gp` (git-profiles) allows you to manage multiple git accounts in the same machine

Use `gp add` to add a new git account to your machine and `gp su` to switch your git account

In case you need to see all the commands available run `gp` or `gp help`

## Install (Linux only)

This command will download the bash script to install the latest binary

```sh
wget -qO- https://raw.githubusercontent.com/RO03M/git-profiles/refs/heads/main/install.sh -q --show-progress | bash
```
